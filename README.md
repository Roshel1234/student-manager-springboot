# Student Management System

A Student Registration System built using Spring Boot,
Thymeleaf and H2 Database.

# Features
- Add students
- View students
- Edit student details
- Delete students
- Input validation

# Technologies Used
- Java
- Spring Boot
- Spring Data JPA
- H2 Database
- Thymeleaf
- HTML and CSS

# How to Run
1. Open the project in VS Code.
2. Run the Spring Boot application.
3. Open http://localhost:8080 in a browser.
